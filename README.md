Task 3 – Sales Dashboard Creation

Project Title

CodeOrbit Sales Dashboard

Tool Used

Microsoft Excel

Objective

To create a sales dashboard using Microsoft Excel to analyze and visualize sales performance based on products, categories, and regions.

Key Performance Indicators (KPIs)

- Total Sales: ₹2,58,000
- Total Orders: 8
- Total Quantity Sold: 24
- Average Order Value: ₹32,250
- Top Product: Laptop – ₹2,00,000

Sales Analysis

- Category-wise Sales
- Region-wise Sales
- Product-wise Sales

Charts and Visualizations

- Column Chart – Category-wise Sales
- Pie Chart – Sales Distribution
- Horizontal Bar Chart – Product-wise Sales

Key Findings

- Electronics generated the highest sales of ₹2,40,000.
- Chennai was the top-performing region with ₹1,94,500.
- Laptop was the best-selling product with ₹2,00,000.
- Mouse recorded the lowest sales of ₹4,500.

Files Included

1. "Dashboard.xlsx" – Excel Sales Dashboard
2. "dashboard task 3.docx" – Project Report

Conclusion

This project demonstrates the use of Microsoft Excel for sales data analysis, visualization, and dashboard creation. It helps understand sales performance and supports better decision-making.
